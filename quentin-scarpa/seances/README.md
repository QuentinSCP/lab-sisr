# Rendus de séance

Chaque séance donne lieu à un ou plusieurs rendus, déposés ici.

## Nommage

`SXX-nom-du-rendu.md` : par exemple `S01-auto-diagnostic.md`, `S02-matrice-missions.md`, `S02-note-de-choix.md`.

En tête de chaque rendu : **ton prénom**, **l'épreuve** et **la date**.

## Ce que tu déposes ici

| Séance | Rendus |
|---|---|
| **S1** | `S01-auto-diagnostic.md` · `S01-regles-du-jeu.md` |
| **S2** | `S02-matrice-missions.md` · `S02-note-de-choix.md` |
| **S3** | *(les pièces de S3 vont dans `03-environnement-annexe-II-E.md` et `annexes/dat/`)* |
| **Suivantes** | Selon la fiche de la séance |

*Les pièces durables (DAT, procédures, tests, schémas) vont dans `annexes/`, pas ici.*
