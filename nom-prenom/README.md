## ✅ Règles du dépôt

- **Aucun secret** (mot de passe, clé privée, jeton) dans aucun fichier : jamais.
- **Aucune donnée réelle** de patient, de médecin ou de salarié.
- **Noms de fichiers** : minuscules, tirets, pas d'espaces ; date `AAAA-MM-JJ` si utile.
- **Un commit par séance au minimum**, avec un message explicite (par exemple `S03 : audit II.E v1`).
- **Ne déclare que ce que tu sais montrer** : une ligne déclarée mais non démontrable est plus risquée qu'une ligne vide.
